# l33t / L33t-zip wrapper

> Lightweight magic+size+zlib wrapper around game state blobs. Used
> by `.age3Yrec` (replays) and `.age3Yscn` (scenarios). Cracked
> 2026-05-09.

## Format

| Offset | Size | Field |
|---|---|---|
| 0 | 4 | Magic — ASCII `l33t` (lowercase) or `L33t` (uppercase) |
| 4 | 4 | Decompressed size (uint32 LE) |
| 8 | … | zlib-deflate stream |

That's the entire wrapper. Inner payload is plain zlib. After
decompression, the bytes are format-specific (replay state stream,
scenario binary tree).

## Examples (verified)

| File | Compressed | Decompressed | Inner first bytes |
|---|---|---|---|
| `Record Game 2026-04-17 14-40-35.age3Yrec` | 9.5 MB | 67.4 MB | binary state stream |
| `age3ycc5a.age3Yscn` (Wonders campaign) | 92 KB | 1.8 MB | `BG;` magic + version + UTF-16 metadata |

## Known issues

- `l33t` (lowercase) and `L33t` (mixed) magics seem interchangeable in practice — our codec accepts both.
- Some scenario files may have nested wrappers (`l33t` containing `alz4`); not yet seen on DE files.
